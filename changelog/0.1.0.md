# 0.1.0

首个正式版本：AI 原生的开发者工具箱，覆盖开发日常最常用的 14 个工具。

## 🚀 新增

- **智能路由引擎**：粘贴任意内容自动识别并路由到正确工具（JWT / JSON / Cron / 时间戳 / Base64 …），即输即转
- **Git 工作台**（SourceTree 式）：打开任意文件夹 / 文件自动识别仓库；文件变更、暂存 / 取消暂存、丢弃、提交、分支管理与切换、提交历史、差异高亮、拉取 / 推送（HTTPS 令牌 + SSH），最近打开记录
- **数据库工具**（原 SQL 工具）：MySQL / PostgreSQL / SQLite 连接管理、数据网格编辑、SQL 高亮 / 补全 / 格式化 / 历史、表设计器、CSV 导出、**用户管理与权限设置**（Navicat 式，双库支持）、密码显示 / 隐藏与钥匙串持久化、连接后拉取数据库列表
- **网络工具**：端口扫描、DNS 查询、TCP / UDP 会话、**链路追踪实时拓扑图**（纯 Rust 实现，不调用外部命令）
- **远程连接**：SSH 多标签终端、会话持久化、快捷命令、文件传输、主机资源监控
- **AI 联动**：全工具接入 OpenAI 兼容流式端点（OpenAI / DeepSeek / Anthropic / Gemini / Ollama），日志 AI 根因定位、SQL 错误解释、正则解释、失败一键 AI 修复
- **四套主题**：深色 / 明亮 / 极光 / 护眼，跟随系统；明亮模式全界面调校
- **全屏模式**：顶栏一键全屏 / 退出（浏览器 + 桌面双端支持）
- 工具显示 / 隐藏设置：侧栏、聚焦框与命令面板可分别控制

## 🎨 体验优化

- 聚焦框空态重设：智能路由引擎 + 能力标签，不再强制展示工具卡片
- 整体视觉升级：深空星点、网格、弧光流光、聚焦框霓虹边框、侧栏标题渐变文字
- 时间戳面板紧凑化：当前时间一键填充，双向转换精简
- 正则表达式：常用表达式速查、实时解释、多出宽度「更多」下拉
- 随机生成：大小写 / 数字 / 符号选项、随机颜色色卡预览
- 悬停变白、页面重叠、字体过小等一批视觉与布局问题修复

## 🛠️ 工程化

- **CI / CD**：GitHub Actions 自动构建并发布 —— Windows（NSIS 安装包 `spurh-windows-x64.exe`、MSI、便携版 zip）与 macOS（Intel / ARM 双架构 DMG 安装包），无需 macOS 便携包
- **Changelog 驱动发布**：`changelog/<版本号>.md` 自动读取为 Release 发布说明；tag `v*` 触发正式 Release，推送 master 触发每日构建
- 前端 212 个测试、Rust 27 个测试全绿；`svelte-check` 0 错误 0 警告

## 🐛 修复

- 明亮主题文字 / 背景对比度异常（顶栏、搜索框、面板）
- 网络工具浏览器模式降级为可用状态
- 图标不统一、面板页脚冗余、时间戳输入框过大等问题
- 数据库密码无法显示 / 无法持久化
- Release 自动发布流水线多次失败问题（产物命名、上传、发布说明）
