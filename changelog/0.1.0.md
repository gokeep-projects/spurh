# 0.1.0

## 新增
- 智能路由引擎：贴入任意内容自动识别并路由到正确工具，即输即转
- 数据库工具：MySQL / PostgreSQL / SQLite 连接、查询、用户管理与权限设置
- 网络工具：端口探测、DNS 查询、链路追踪、TCP/UDP 会话（纯 Rust 实现，不调用外部命令）
- 远程连接：SSH 终端会话管理
- 工具显示/隐藏设置：侧栏、聚焦框与命令面板可分别控制
- 时间戳、加解密、随机生成、Cron、正则、编码转换、剪贴板历史等 13 个工具

## 优化
- 聚焦框空态重设：智能路由引擎 + 能力标签，不再强制展示工具卡片
- 整体视觉升级：深空星点、网格、弧光流光、聚焦框嫁光边框
- 侧栏工具标题渐变文字 + 发光动效

## 修复
- 视觉与布局问题一批量修复
- 网络工具浏览器模式降级为可用状态
- Release 自动发布流水线稳定运行
